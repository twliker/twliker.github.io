📌 애플리케이션 소개 (About Application)

TW-Overlay는 PC 데스크톱 환경에서 실행되는 올인원 게임 편의 및 숙제 체크리스트 오버레이 도구입니다. 사용자에게 쾌적한 게임 환경과 자동화된 정보 요약을 제공합니다.

🔒 Google API 및 사용자 데이터 사용 정책 (Google API User Data Policy)

TW-Overlay는 사용자가 명시적으로 구글 계정을 연동할 때 Google Drive API (드라이브 앱 데이터 스코프)를 사용합니다.

☁️ Google 데이터 사용 목적 및 제한적 사용 (Limited Use)

  • 요청 권한: https://www.googleapis.com/auth/drive.appdata (Application Data Folder)
  • 사용 목적: 사용자의 여러 PC 간에 숙제 완료 상태와 개인 설정 파일(JSON)을 백업 및 동기화하기 위한 용도로만 사용됩니다.
  • 데이터 격리 보장: 오직 TW-Overlay가 생성한 앱 전용 숨김 폴더에만 접근하며, 사용자의 Google Drive 내 일반 문서, 사진 등 개인 파일에는 일체 접근하지 않습니다.
  • 외부 서버 미전송: 개발자나 중앙 서버로 사용자의 구글 계정 정보나 데이터를 전송하거나 저장하지 않습니다.
  • 타 용도 금지: 사용자 데이터를 광고 타겟팅, 제3자 제공, AI 모델 학습 등에 절대 활용하지 않습니다.
